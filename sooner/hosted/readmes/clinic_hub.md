# Sooner Clinic Hub

Hosts several demo clinics in one agent and routes every request by clinic_id. Clinic owners can
manage slots by chatting here, starting with the clinic id: `<clinic_id>: add slot 2026-10-28T10:00 150`,
`<clinic_id>: list slots`, `<clinic_id>: cancel booking <slot_id>`.

_Demo: clinics and payments are simulated._
